# 優然｜立繪改版概念

**人設方向：他知道你在看他。** 優然是個手上有活、嘴上帶笑的成年工匠。挑逗感主要由視線、表情和姿勢來傳達。

參考圖以半寫實的立體光影畫出銀髮、汗光與磨舊工裝。深眉、紅棕眼、俐落的下顎和眼下小痣構成臉部記憶點；他直視鏡頭，嘴角有一點笑意，跟手套、工具和油污形成反差。遊戲現版初始立繪保留了服裝和體格，但低頭看工具，少了與玩家對視的那一下。

新版保留白色羅紋背心、識別牌、肩上毛巾和紅黑工具腰帶。把目光拉回玩家，讓一邊嘴角微揚；一手抓著毛巾、一手靠在腰帶上，重心偏一側。用暖色側逆光勾出髮絲，臉部補光保住眼神。台詞方向：「你盯我這麼久，想好要出哪一拳了嗎？」

客戶認可的定調稿 `youran-v2-concept.webp` 是四階段的臉型、髮型、表情與打光母稿。四張皆以 1024 × 1536 透明畫布輸出，套用同一縮放比例，對齊可見鞋底至 y=1505（透明度至少 128，座標不含該列）。牌桌 WebP 與收藏 PNG 使用同一構圖和透明通道。

| 階段 | CG | 動作與造型 |
| --- | --- | --- |
| 0 | 工匠邀約 | 白色背心，一手抓毛巾，一手勾工具腰帶。 |
| 1 | 熱身過後 | 手臂斜過胸前，用毛巾擦對側肩頭，另一手撐在工具腰帶上。 |
| 2 | 撥髮迎戰 | 側身回望，手肘向外打開，把瀏海往後撥，另一手提著摘下的手套。 |
| 3 | 優然終幕 | 磚紅短版運動緊身褲，貼身褲腳與無抽繩腰頭。一手搭後頸，一手向玩家攤開，歪頭眨眼、偏嘴笑。 |

測試服終幕使用 `youran-stage-3-towel.png` 和 `images/yakyuken/youran/stage-3-towel.webp`，採用驗收的無背心浴巾版。以內建圖像工具局部修掉手套和工作靴，再接回原圖，保留眼神、肩頸、識別牌、暖光、汗光和浴巾。沿用前三張的 1024 × 1536 透明畫布，腳底對齊 y=1505。PNG 與無損 WebP 解碼後像素相同。

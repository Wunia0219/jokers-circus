# 野球拳：荷官獨立試玩

此原型只在本機運作，不匯入 Discord、正式錢包或老虎機流程，不部署、不改產品版本。進度與 10,000 初始試玩戲籌使用獨立的 sessionStorage key；重新整理會保留，同分頁關閉後不保證保留。正式串接需要後端管理出拳、挑戰狀態、防重送與錢包交易，不能使用這份前端試玩帳本。

## 開啟與驗證

在專案根目錄執行 `node scripts/game/yakyuken-preview.js`，以符合 `.node-version` 的 Node 啟動。Windows 已備妥 `.tools/node-x64/node-v24.22.1-win-x64/node.exe` 可直接使用。

入口為 http://127.0.0.1:4195/yakyuken-preview.html 。伺服器只監聽本機且不讀取 `.env`。原本正式 Vite 建置入口與停輪基準皆未修改。

- `node --test tests/yakyuken.test.js`：規則、數學、重複輸入、恢復與一次發獎。
- `node scripts/game/yakyuken-preview.js --build`：獨立輸出至忽略版控的 `test-results/yakyuken-preview`。
- `node scripts/qa/yakyuken-preview.js`：桌機、手機、換圖遮罩同步、重整恢復、素材失敗、減少動態效果與正式資料隔離；證據位於 `test-results/yakyuken`。
- 專案完整回歸依 `docs/testing.md` 執行 `npm run verify:ci`；本機結果不能視為遠端 CI 結果。

## 本次暫定規則

- 每次挑戰收取 1,000 戲籌，挑戰內每拳不重複收費。
- 獨立等機率石頭／布／剪刀，平手重猜、不扣機會，沒有平手次數上限。
- 累積 2 勝通關；輸第 2 次結束，相當於可承受 1 次落敗。失敗不扣已獲得的勝場。
- 通關總入帳 2,000 戲籌，計入入場費後淨獲得 1,000；失敗不發獎。
- 這些未明定的規則是為可試玩而採用的假設，需使用者驗收後定案。

## 角色及素材邊界

`src/games/yakyuken/` 自包含規則、角色設定、試玩狀態、控制器、音效、畫面與演出。圖檔獨立於 `images/yakyuken/dealer/`。未來四位角色已保留 3／5／7／9 勝及 5,000／10,000／25,000／50,000 獎勵設定；失敗門檻為 null，暫不開放。

三階段以相同角色身分、黑銀髮色與繪畫風格為基準，允許服裝、姿勢和長髮位置改變。依使用者回饋固定髮際線、分線、瀏海與頭頂輪廓，不增加頭頂髮髻。開場為重新設計的酒紅襯衫與黑背心；中間為襯衫、自然撥髮及剪刀手勢；終幕為後頸低束長髮、赤膊與一般合身黑長褲。圖檔使用 1024×1536 畫布並保留完整人物，實際邊界記錄於素材 manifest。

素材使用內建 `image_gen.imagegen` 產生。原畫存為像素不變的 lossless WebP，遊戲載入另用 WebP 品質 93；均保留透明度、不裁切。完整提示詞與來源記錄於 `art/yakyuken/dealer/generation.json`。

獲勝時先揭曉猜拳，再以畫面正中央的勝利徽章、背景暗幕吸引目光；在徽章出現後更換人物圖並播放勝利音效，最後揭曉造型。輸入在演出中鎖定。結果和獎勵先保存，動畫失敗、重整或取消不反轉結算，也不重複發獎。減少動態效果時直接切到正確結果；切入背景會取消等待並完成收尾。

## 精確機率試算

公平猜拳排除平手後，勝敗各為 1/2。以 `P(w,l)` 表示尚需 w 勝、尚可輸 l 次時的通關率，邊界 `P(0,l)=1`、`P(w,0)=0`，其餘 `P(w,l)=(P(w-1,l)+P(w,l-1))/2`。`rules.js` 使用動態規劃計算，測試另以完整分支枚舉交叉驗證五位角色。

通關率乘以獎勵、再除以 1,000 入場費，即為理論返還率。平手不影響通關率，但每個有勝負的回合平均需要 1.5 次出拳。

荷官在輸第 1／2／3 次結束的通關率為 25%／50%／68.75%，理論返還率為 50%／100%／137.5%。暫選第 2 次結束，平均需要 3.75 次出拳完成一次挑戰。

若其他角色都採輸第 2 次結束：3 勝通關率 31.25%、返還率 156.25%；5 勝為 10.9375%、109.375%；7 勝為 3.515625%、87.890625%；9 勝為 1.07421875%、53.7109375%。因此同一個失敗門檻不會得到相同經濟回報；目前不擅自調整勝率或獎勵。

遊戲頁下方「機會次數試算」可查看五位角色在輸第 1／2／3 次結束的精確結果。未來需先確認目標返還率與難度，再決定機會或是否調整獎勵；本次僅試作荷官。

若條件是「維持公平猜拳，理論返還率不超過 100%，在此條件內給最多機會」，五位角色的失敗門檻候選為輸第 2／1／1／2／2 次結束，返還率依序為 100%／62.5%／31.25%／87.890625%／53.7109375%。其中 3 勝與 5 勝角色完全不能輸，體驗會比較嚴格。這是帶條件的經濟試算，不是已決定的玩法；使用者的獎勵與勝場設定維持原值。

# 1.1.1 正式雙遊戲整合

本版依 2026-11-14 授權整合分支到 main，將正式服接入雙遊戲、後台、收藏圖庫及最新推播。部署完成狀態另以實際 health、版本 ID、main SHA 與遠端 CI 核對；本文件不以候選建置冒充已上線。

## 行為

- 保留最近三次使用者修改，包括五位角色公告設計、色洛七張更新及玩家錯誤訊息整理。萬世冷白膚色、冷酷表情與第八／九勝散髮、黑皮鞋沿用已核准素材。
- 正式服沿用既有 Discord 指令。測試預覽中的通關卡、三種離場收據與發放收據接入真正 Bot 事件，使用已驗證玩家及權威結算數字；沒有新增正式預覽指令。
- 通關公告與派彩原子建立，原請求重播不重複公告；429 等待跨重啟保留，結果不明不自動重貼。
- 測試服維持無 Bot、私人指令預覽、全 CG 檢視與既有專屬素材。正式與測試的 App、DO、資料庫、金鑰及頻道保持隔離。
- 正式雙遊戲後台保留既有記住登入功能，與測試服共用同源、HttpOnly 與金鑰隔離保護。
- 不改動已驗收停輪、動畫、冷卻、權威結算與歷史同步時序。

## 優化與資料保護

- 入離場可直接使用唯一 writer 的有效已提交快取，暖快取情況省去一次錢包文件讀取；這是該讀取路徑的節省，不宣稱整體雲端帳單或速度提升比例。過期、失效、時鐘倒退及結算等待都有驗證。
- 野球拳離場統計只查本次起點之後的分類帳目，排除簽到／管理發放；共用預覽與正式收據產生器，移除不用的靜態收據。
- 開場僅預上傳首張人物貼圖的隔離比較：冷快取、40 ms 延遲、10 Mbps、前後各三次；中位數 13,334.5 → 13,108.1 ms，僅改善 1.70%，低於使用者 5% 門檻，未套用。
- 2026-11-14 16:18（台灣）正式快照 rev 23727：30 錢包、23,637 原請求於全新本機目錄還原重播，七表及來源雜湊不變，未聯絡外部服務或寫回正式資料。當時尚無正式野球拳收據；新遊戲恢復另由隔離整合測試覆蓋。

## 驗證與部署紀錄

完整 `npm run verify:ci`、三個私有歷史快照案例、正式／測試發布預檢、後台、收藏 31 張下載及遠端 CI 的本次證據保存在忽略版控的 `test-results/release-1.1.1/`。私有還原內容在 `data/recovery/`；不得提交備份、金鑰或玩家明細。

更新沿用既有服務與有效資料，不重新 seed、不 reset、不提高或清空用量。正式與測試各自保存實際線上舊雜湊素材，供已開啟視窗繼續載入。Netlify 沿用原靜態預覽用途；正式 Discord 遊戲與權威後端由 Cloudflare 提供。

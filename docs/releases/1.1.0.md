## 準備內容

- `production-arcade` 是明確選用的正式雙遊戲建置；預設 `npm run build` 仍為單一老虎機。候選產物與現行正式設定分開。
- 正式／測試共用 `cloud/worker.js`、權威錢包、原請求去重與備份恢復；保留各環境的 App、DO、資料庫與通知政策。
- 萬世十張採已核准的冷白膚色、冷酷表情；第八、九勝保留散髮及黑皮鞋。PNG 與遊戲 WebP 沿用同一構圖。
- 建置、預覽、Discord 設定及雲端 CLI 依責任分類；舊測試活動文件移至 `docs/history/`。三個重複 UI 轉出口已移除，直接使用 `src/ui/pixi/`。
- 修正大廳登入失敗、圖片／renderer 初始化失敗、途中離開與正常關閉的資源回收；加入五種實際 Pixi 生命週期驗證。
- 補齊 Docker 建置腳本、野球拳規則及恢復工具相依，排除本機雲端／部署狀態；CI 驗證實際 Docker 建置與模組載入。

文件已修正 README 舊版本、現行野球拳後端與早期測試後端混淆、規則來源、CG 入場解鎖與 CI 清單。較高風險的結算引擎重寫、歷史收據裁切、動畫重新切圖不納入這次上架前整理。
